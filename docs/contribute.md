# Contribute

Hayate is pre-1.0 and evidence-driven. The most useful contributions improve a
real application path, close a reproducible compatibility gap, or make a
contract easier to verify.

## Find the right repository

- Framework and runtime adapters: [`hayate`](https://github.com/hayatepy/hayate)
- Authentication and OAuth: [`hayate-auth`](https://github.com/hayatepy/hayate-auth)
- MCP: [`hayate-mcp`](https://github.com/hayatepy/hayate-mcp)
- OpenAPI and typed contracts: [`hayate-openapi`](https://github.com/hayatepy/hayate-openapi)
- SQL: [`hayate-sql`](https://github.com/hayatepy/hayate-sql)
- Project generation: [`create-hayate`](https://github.com/hayatepy/create-hayate)
- This site: [`hayatepy/docs`](https://github.com/hayatepy/docs)

Read the
[organization contribution guide](https://github.com/hayatepy/.github/blob/main/CONTRIBUTING.md)
before opening a pull request.

## Design partners

The design-partner program seeks owner-external applications in three tracks:
conventional ASGI, MCP or agent backends, and Cloudflare Workers. It records
time to first test, local request, deployment, dependency footprint, and every
maintainer intervention.

[Read the bounded program and apply](https://github.com/hayatepy/.github/blob/main/docs/DESIGN_PARTNERS.md){ .md-button }

## Security

Do not open a public issue for a vulnerability. Use the affected repository's
**Security → Report a vulnerability** flow. `hayate-auth` has extensive
attack-regression coverage but has not yet completed an independent security
audit.
